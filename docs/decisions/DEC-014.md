# DEC-014 — CORS origins

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Development allows only `http://localhost:5173`. Production reads one explicit `FRONTEND_ORIGIN`; wildcard origins are forbidden. CORS credentials are enabled because authentication uses cookies. The policy is configured by environment and tested for allowed and rejected origins.

## Rationale

The Vite development port and the API are separate origins. Explicit origins avoid unsafe wildcard credential behavior.

## Impact

Applies to TASK-005, TASK-013, TASK-055 and frontend environment configuration.

## Evidence

The specification requires CORS but does not define origins or credential behavior.
