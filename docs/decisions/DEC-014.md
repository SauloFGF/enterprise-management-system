# DEC-014 — Origens do CORS

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Desenvolvimento permite apenas `http://localhost:5173`. Produção lê uma `FRONTEND_ORIGIN` explícita; origens wildcard são proibidas. Credenciais CORS são habilitadas porque a autenticação utiliza cookies. A política é configurada por ambiente e testada para origens permitidas e rejeitadas.

## Justificativa

A porta de desenvolvimento do Vite e a API são origens separadas. Origens explícitas evitam comportamento inseguro de wildcard com credenciais.

## Impacto

Aplica-se à TASK-005, TASK-013, TASK-055 e configuração de ambiente do frontend.

## Evidência

A especificação requer CORS, mas não define origens ou comportamento de credenciais.
