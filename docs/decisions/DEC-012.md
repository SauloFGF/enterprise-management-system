# DEC-012 — Ciclo de vida do refresh token

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar um refresh token opaco e aleatório por sessão de User. Persistir apenas um hash SHA-256 em `User.RefreshToken`; armazenar a expiração em `User.RefreshTokenExpiresAt`. Lifetime absoluto de sete dias. Rotacionar o token a cada refresh bem-sucedido e revogar o token anterior. Logout revoga a sessão atual. Mudança de senha, mudança de role ou soft deletion revoga o token. Existe uma sessão ativa por usuário no MVP; sessões multi-dispositivo não são suportadas.

## Justificativa

Hash em repouso e rotação reduzem a exposição do token, enquanto a semântica de uma sessão mantém os campos de User especificados simples.

## Impacto

Aplica-se à TASK-006, TASK-019 a TASK-021, TASK-023 e testes de auth.

## Evidência

A especificação requer refresh tokens de sete dias, persistidos e revogáveis, mas não define rotação ou formato de armazenamento.
