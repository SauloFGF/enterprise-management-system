# DEC-002 — Pagination and filters

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use one-based `page` and `pageSize` query parameters. Default `page=1`; default `pageSize=20`; maximum `pageSize=100`. List responses contain `items`, `page`, `pageSize`, `totalItems` and `totalPages`.

Resource filters are explicit query parameters. Users support `search`, `role` and `isDeleted` for management screens; Clients support `search`, `type` and `document`; Products support `search`; Orders support `status`, `clientId` and `document`. Text search is case-insensitive and uses normalized values.

## Rationale

The product requires pagination and filters but does not prescribe names. This format is small, predictable and easy to consume in React.

## Impact

Applies to TASK-004, TASK-027, TASK-032, TASK-037, TASK-042, TASK-049 and all list UIs.

## Evidence

The source specification explicitly lists pagination and filters as differentiators.
