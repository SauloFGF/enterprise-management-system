# DEC-020 — Banco de dados de testes

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar um banco de dados PostgreSQL isolado via Testcontainers para testes de integração e E2E. Não utilizar EF InMemory ou SQLite para testes que verificam comportamento PostgreSQL. Cada execução de teste utiliza um ciclo de vida de banco/schema isolado e limpa apenas o seu próprio container. Nenhum threshold de cobertura numérica é requerido para o MVP; a suite deve reportar testes executados e falhas.

## Justificativa

Comportamento específico do PostgreSQL, migrations, precisão numérica e comportamento de exclusão devem ser testados contra o provedor real. InMemory esconderia essas falhas.

## Impacto

Aplica-se à TASK-014, TASK-015, TASK-052, TASK-053, TASK-054 e CI. Docker torna-se um pré-requisito de desenvolvimento/teste para testes de integração, não um requisito de runtime da aplicação.

## Evidência

A especificação requer PostgreSQL e testes de integração/E2E, mas deixa a infraestrutura de testes pendente.
