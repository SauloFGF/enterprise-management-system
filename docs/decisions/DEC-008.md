# DEC-008 — Order status transitions

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

The state machine is:

```text
Pendente -> Concluído
Pendente -> Cancelado
Concluído -> terminal
Cancelado -> terminal
```

Only `Pendente` orders may be edited through `PUT /api/orders/{id}`. Status changes use `PATCH /api/orders/{id}/status`. Repeating the same status is idempotent; moving backward or changing a terminal status returns `409`.

## Rationale

This prevents completed or cancelled financial history from being silently rewritten and gives the UI deterministic actions.

## Impact

Applies to TASK-009, TASK-041, TASK-044, TASK-045, TASK-046 and Order tests.

## Evidence

The specification names the three statuses but does not define transitions.
