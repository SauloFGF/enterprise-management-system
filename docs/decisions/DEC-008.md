# DEC-008 — Transições de status do Pedido

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

A máquina de estados é:

```text
Pendente -> Concluído
Pendente -> Cancelado
Concluído -> terminal
Cancelado -> terminal
```

Apenas pedidos `Pendente` podem ser editados via `PUT /api/orders/{id}`. Mudanças de status utilizam `PATCH /api/orders/{id}/status`. Repetir o mesmo status é idempotente; mover para trás ou mudar um status terminal retorna `409`.

## Justificativa

Isso previne que histórico financeiro concluído ou cancelado seja silenciosamente reescrito e fornece ações determinísticas para a UI.

## Impacto

Aplica-se à TASK-009, TASK-041, TASK-044, TASK-045, TASK-046 e testes de Order.

## Evidência

A especificação nomeia os três status, mas não define transições.
