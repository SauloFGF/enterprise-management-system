# DEC-018 — Frontend routes and states

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use these routes: `/login`, `/dashboard`, `/users`, `/clients`, `/products` and `/orders`. `/login` is public; the others require authentication; `/users` additionally requires ADMIN. Unknown routes render a not-found page. Every data page has explicit loading, empty, error and retry states. There is no public registration or password-recovery route in the MVP.

## Rationale

The route names are conventional and directly reflect the specified modules.

## Impact

Applies to TASK-012, TASK-023, TASK-024 and all UI tasks.

## Evidence

The specification defines pages and behavior but not paths or UX states.
