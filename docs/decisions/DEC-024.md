# DEC-024 — Logging and correlation IDs

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use structured logging with a correlation ID. Accept a valid incoming `X-Correlation-ID` or generate a UUID, return it in the response header and include it in ProblemDetails. Log route, status, elapsed time, user ID when authenticated and safe exception metadata. Never log passwords, raw tokens, signing keys, connection strings or full sensitive documents. Authentication success/failure and User mutations should produce audit events.

## Rationale

Traceability is needed for verification and release evidence without exposing sensitive data.

## Impact

Applies to TASK-004, TASK-005, TASK-055, TASK-057, TASK-059 and observability tests.

## Evidence

The specification requires security, evidence and error handling but does not define logging format.
