# DEC-024 — Logging e correlation IDs

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar logging estruturado com correlation ID. Aceitar um `X-Correlation-ID` de entrada válido ou gerar um UUID, retorná-lo no header de resposta e incluí-lo no ProblemDetails. Logar rota, status, tempo decorrido, user ID quando autenticado e metadados seguros de exceção. Nunca logar senhas, tokens brutos, chaves de assinatura, connection strings ou documentos sensíveis completos. Sucesso/falha de autenticação e mutações de User devem produzir eventos de auditoria.

## Justificativa

Rastreabilidade é necessária para verificação e evidência de release sem expor dados sensíveis.

## Impacto

Aplica-se à TASK-004, TASK-005, TASK-055, TASK-057, TASK-059 e testes de observabilidade.

## Evidência

A especificação requer segurança, evidências e tratamento de erros, mas não define formato de logging.
