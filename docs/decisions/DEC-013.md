# DEC-013 — Browser token storage

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Store access and refresh tokens only in `HttpOnly`, `Secure` cookies. The frontend uses `credentials: include` and never reads token values from JavaScript. Set `SameSite=Lax`; use a CSRF token/header for state-changing cookie-authenticated requests. Login, refresh and logout responses do not expose raw tokens in JSON.

## Rationale

HttpOnly cookies reduce token exposure through browser JavaScript. CSRF protection is required because cookies are sent automatically.

## Impact

Applies to TASK-004, TASK-013, TASK-017, TASK-018, TASK-020, TASK-021, TASK-023 and security tests.

## Evidence

The specification requires JWT and refresh token but leaves browser storage and transport pending.
