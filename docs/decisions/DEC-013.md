# DEC-013 — Armazenamento de token no navegador

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Armazenar access e refresh tokens apenas em cookies `HttpOnly` e `Secure`. O frontend utiliza `credentials: include` e nunca lê valores de token via JavaScript. Definir `SameSite=Lax`; utilizar token/header CSRF para requisições que alteram estado autenticadas via cookie. Respostas de login, refresh e logout não expõem tokens brutos em JSON.

## Justificativa

Cookies HttpOnly reduzem a exposição do token via JavaScript do navegador. Proteção CSRF é necessária porque cookies são enviados automaticamente.

## Impacto

Aplica-se à TASK-004, TASK-013, TASK-017, TASK-018, TASK-020, TASK-021, TASK-023 e testes de segurança.

## Evidência

A especificação requer JWT e refresh token, mas deixa armazenamento no navegador e transporte pendentes.
