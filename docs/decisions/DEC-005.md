# DEC-005 — Comportamento referencial de exclusão

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar `RESTRICT` do banco de dados para exclusões físicas de chaves estrangeiras. Operações de exclusão pública apenas setam o flag `IsDeleted` da raiz. Um Client ou Product soft-deleted permanece referenciado por Orders/OrderItems históricos; queries podem retornar um rótulo de referência deletada, mas nunca remover fisicamente a linha. Um Order soft-deleted oculta seus itens das queries normais, preservando-os.

## Justificativa

RESTRICT previne perda acidental de histórico de pedidos. Soft delete mantém a UI e o banco de dados consistentes sem cascatas destrutivas.

## Impacto

Aplica-se à TASK-010, TASK-011, TASK-032, TASK-037 e testes de Order.

## Evidência

A especificação requer soft delete e define relacionamentos Client → Order → OrderItem → Product, mas não define comportamento de cascata.
