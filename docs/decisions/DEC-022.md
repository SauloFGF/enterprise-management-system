# DEC-022 — Runtime and package versions

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Pin the repository toolchain to the versions currently used by the project: .NET SDK `10.0.401` with `global.json`, Node `24.21.0` through `engines`/`.nvmrc`, and the versions already locked in `frontend/package-lock.json`. CI and local setup must use the same major/minor toolchain. Upgrade versions only through an explicit task and validation run.

## Rationale

Reproducible builds are more valuable for a portfolio than floating latest versions.

## Impact

Applies to TASK-002, TASK-012, TASK-058 and setup documentation.

## Evidence

Repository inspection found the SDK/runtime versions and no `global.json` or Node version file.
