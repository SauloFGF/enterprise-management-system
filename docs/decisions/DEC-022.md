# DEC-022 — Versões de runtime e pacotes

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Fixar a toolchain do repositório nas versões atualmente utilizadas pelo projeto: .NET SDK `10.0.401` com `global.json`, Node `24.21.0` através de `engines`/`.nvmrc`, e as versões já locked em `frontend/package-lock.json`. CI e setup local devem utilizar a mesma toolchain major/minor. Fazer upgrade de versões apenas através de uma task explícita e execução de validação.

## Justificativa

Builds reproduzíveis são mais valiosos para um portfolio do que versões flutuantes latest.

## Impacto

Aplica-se à TASK-002, TASK-012, TASK-058 e documentação de setup.

## Evidência

Inspeção do repositório encontrou as versões de SDK/runtime e nenhum `global.json` ou arquivo de versão do Node.
