# DEC-011 — JWT configuration

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use `HS256` for the single API service. Configure issuer `enterprise-management-api`, audience `enterprise-management-web`, signing key from environment/user secrets, minimum key length of 32 bytes, and 30 seconds of clock skew. Validate signature, issuer, audience, lifetime and required claims. Access-token lifetime is exactly 15 minutes. Do not commit the key or accept unsigned tokens.

## Rationale

HS256 is simple and appropriate for a single-service portfolio while still enforcing signed, scoped tokens. The key remains external to source.

## Impact

Applies to TASK-002, TASK-017, TASK-018, TASK-022 and auth tests.

## Evidence

The specification requires a signed JWT, 15-minute expiration and claims `sub`, `email`, `role`; algorithm and key management were pending.
