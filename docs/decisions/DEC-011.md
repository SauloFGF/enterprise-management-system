# DEC-011 — Configuração do JWT

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar `HS256` para o serviço de API único. Configurar issuer `enterprise-management-api`, audience `enterprise-management-web`, chave de assinatura a partir de environment/user secrets, comprimento mínimo de chave de 32 bytes e 30 segundos de clock skew. Validar assinatura, issuer, audience, lifetime e claims obrigatórios. O lifetime do access token é exatamente 15 minutos. Não commitar a chave ou aceitar tokens não assinados.

## Justificativa

HS256 é simples e apropriado para um portfolio de serviço único, ainda que exija tokens assinados e com escopo. A chave permanece externa ao código-fonte.

## Impacto

Aplica-se à TASK-002, TASK-017, TASK-018, TASK-022 e testes de auth.

## Evidência

A especificação requer JWT assinado, expiração de 15 minutos e claims `sub`, `email`, `role`; algoritmo e gerenciamento de chave estavam pendentes.
