# DEC-023 — Connection, migrations and seed

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Read PostgreSQL configuration from `ConnectionStrings__Postgres` or user secrets. Apply EF migrations explicitly with `dotnet ef database update`; do not run migrations automatically during application startup. The development seed reads `ADMIN_SEED_EMAIL` and `ADMIN_SEED_PASSWORD` only in Development/Test and never contains a source default. Migration rollback must be documented; destructive reset is not part of normal validation.

## Rationale

Explicit migrations make environment changes auditable and prevent accidental schema changes at startup.

## Impact

Applies to TASK-002, TASK-003, TASK-007, TASK-011, TASK-056, TASK-058 and TASK-059.

## Evidence

PostgreSQL and migrations are required, while connection and promotion procedures were unspecified.
