# DEC-015 — Rate limiting

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Aplicar um limitador de janela fixa de 10 requisições por minuto por IP do cliente nos endpoints de login e refresh. Aplicar um limite de 120 requisições/minuto ao tráfego autenticado da API por usuário, caindo para IP quando nenhum usuário estiver disponível. Retornar `429` com `Retry-After`. Limites são configuráveis via options, mas estes valores são os padrões do portfolio.

## Justificativa

Endpoints de auth precisam de proteção contra abuso, enquanto requisições normais de negócio não devem ser inutilizáveis para um único operador. Valores configuráveis suportam ajustes sem mudanças de código.

## Impacto

Aplica-se à TASK-005, TASK-018, TASK-020, TASK-055 e testes de segurança.

## Evidência

Rate limiting é um requisito de segurança; limites numéricos não foram especificados.
