# DEC-015 — Rate limiting

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Apply a fixed-window limiter of 10 requests per minute per client IP to login and refresh endpoints. Apply a 120 requests/minute limit to authenticated API traffic per user, falling back to IP when no user is available. Return `429` with `Retry-After`. Limits are configurable through options but these values are the portfolio defaults.

## Rationale

Auth endpoints need abuse protection, while normal business requests should not be unusable for a single operator. Configurable values support tuning without code changes.

## Impact

Applies to TASK-005, TASK-018, TASK-020, TASK-055 and security tests.

## Evidence

Rate limiting is a security requirement; numeric limits were not specified.
