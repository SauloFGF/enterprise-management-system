# DEC-010 — Senha de Usuário e bootstrap

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Normalizar email de User para lowercase e impor unicidade entre todos os usuários. Senhas devem ter 8–72 caracteres e conter pelo menos uma letra e um número; BCrypt recebe a senha completa. Não expor PasswordHash. Fazer bootstrap do primeiro ADMIN a partir de `ADMIN_SEED_EMAIL` e `ADMIN_SEED_PASSWORD` apenas em Development/Test, nunca com um default no código-fonte. O sistema previne exclusão ou rebaixamento de role do último ADMIN ativo.

## Justificativa

Essas regras fornecem uma base de portfolio segura e testável sem introduzir recuperação de senha ou MFA não solicitados.

## Impacto

Aplica-se à TASK-006, TASK-012, TASK-016, TASK-018, TASK-024, TASK-026, TASK-028 e testes de User.

## Evidência

A especificação define roles e PasswordHash, mas deixa regras de senha, email e bootstrap pendentes.
