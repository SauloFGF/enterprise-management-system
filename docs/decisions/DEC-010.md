# DEC-010 — User password and bootstrap

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Normalize User email to lowercase and enforce uniqueness across all users. Passwords must be 8–72 characters and contain at least one letter and one number; BCrypt receives the complete password. Do not expose PasswordHash. Bootstrap the first ADMIN from `ADMIN_SEED_EMAIL` and `ADMIN_SEED_PASSWORD` only in Development/Test, never with a source default. The system prevents deletion or role demotion of the last active ADMIN.

## Rationale

These rules provide a secure, testable portfolio baseline without introducing unrequested password recovery or MFA.

## Impact

Applies to TASK-006, TASK-012, TASK-016, TASK-018, TASK-024, TASK-026, TASK-028 and User tests.

## Evidence

The specification defines roles and PasswordHash but leaves password, email and bootstrap rules pending.
