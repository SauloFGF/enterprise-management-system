# DEC-019 — Estilo da API

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar minimal APIs do ASP.NET Core, agrupadas por funcionalidade através de métodos de extensão de endpoint. Manter handlers finos: autorização, binding e preocupações HTTP permanecem na Api; casos de uso permanecem na Application. Não introduzir controllers no MVP.

## Justificativa

O host atual já utiliza minimal APIs e este estilo mantém a implementação do portfolio compacta, preservando os limites da arquitetura limpa.

## Impacto

Aplica-se à TASK-005 e a todas as tasks de endpoint (TASK-018, TASK-020, TASK-021, TASK-028, TASK-033, TASK-038, TASK-045, TASK-049).

## Evidência

A especificação define rotas e camadas, mas não estilo de endpoint; o Program.cs atual estabelece uma convenção, não um requisito.
