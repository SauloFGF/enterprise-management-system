# DEC-019 — API style

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use ASP.NET Core minimal APIs, grouped by feature through endpoint extension methods. Keep handlers thin: authorization, binding and HTTP concerns stay in Api; use cases remain in Application. Do not introduce controllers in the MVP.

## Rationale

The current host already uses minimal APIs and this style keeps the portfolio implementation compact while preserving clean architecture boundaries.

## Impact

Applies to TASK-005 and every endpoint task (TASK-018, TASK-020, TASK-021, TASK-028, TASK-033, TASK-038, TASK-045, TASK-049).

## Evidence

The specification defines routes and layers but not endpoint style; the current Program.cs establishes a convention, not a requirement.
