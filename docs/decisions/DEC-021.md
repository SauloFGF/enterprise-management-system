# DEC-021 — Plataforma CI/CD

**Status:** APROVADO  
**Data:** 24/09/2026  
**Responsável:** Tech Lead

## Decisão

Utilizar GitHub Actions porque o remote do repositório é `https://github.com/SauloFGF/enterprise-management-system.git`. Executar validação em pull requests e pushes para `main`: restore, build/testes do backend, install/lint/testes/build do frontend, security audit e Playwright quando o ambiente de teste estiver disponível. O pipeline do MVP publica artefatos de build/teste; deploy em produção permanece fora de escopo até que um destino de hosting seja escolhido.

## Justificativa

O remote real é GitHub, então GitHub Actions evita uma camada de integração desnecessária, ainda que forneça gates reproduzíveis.

## Impacto

Aplica-se à TASK-058 e documentação de release. Secrets e configuração de assinatura utilizam secrets do GitHub Actions, nunca arquivos do código-fonte.

## Evidência

Inspeção do remote do repositório mostrou GitHub como origem; a especificação não requer um vendor de CI específico.
