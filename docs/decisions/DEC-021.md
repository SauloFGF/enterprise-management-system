# DEC-021 — CI/CD platform

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use GitHub Actions because the repository remote is `https://github.com/SauloFGF/enterprise-management-system.git`. Run validation on pull requests and pushes to `main`: restore, backend build/tests, frontend install/lint/tests/build, security audit and Playwright when the test environment is available. The MVP pipeline publishes build/test artifacts; production deployment remains outside scope until a hosting target is chosen.

## Rationale

The actual remote is GitHub, so GitHub Actions avoids an unnecessary integration layer while still providing reproducible gates.

## Impact

Applies to TASK-058 and release documentation. Secrets and signing configuration use GitHub Actions secrets, never source files.

## Evidence

Repository remote inspection showed GitHub as the origin; the specification does not require a particular CI vendor.
