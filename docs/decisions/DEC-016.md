# DEC-016 — Security headers and HTTPS

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use HTTPS in non-development environments and enable HSTS only in production. Return `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Permissions-Policy: camera=(), microphone=(), geolocation=()` and a restrictive API CSP. Do not disable TLS validation in any environment.

## Rationale

The headers reduce common browser attack surfaces while production HSTS enforces HTTPS after first secure load.

## Impact

Applies to TASK-005, TASK-055, TASK-059 and deployment configuration.

## Evidence

The specification requires HTTPS and security headers but does not list exact values.
