# DEC-007 — Money and rounding

**Status:** APPROVED  
**Date:** 24/09/2026  
**Owner:** Tech Lead

## Decision

Use PostgreSQL `numeric(18,2)` for `Price`, `UnitPrice`, `TotalPrice` and `TotalAmount`. Treat the currency as BRL for the portfolio; no separate Currency field is added to the specified entities. Calculate each line total as `round(Quantity * UnitPrice, 2)` and `TotalAmount` as the sum of persisted line totals. All calculations occur on the server.

## Rationale

Fixed-scale numeric avoids floating-point errors and gives deterministic totals. BRL fits the Portuguese business context and keeps the MVP within the specified fields.

## Impact

Applies to TASK-008, TASK-009, TASK-036, TASK-037, TASK-041, TASK-043 and Order tests.

## Evidence

The specification defines monetary fields but not currency, precision or rounding.
